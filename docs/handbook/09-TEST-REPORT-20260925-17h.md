## 3. Test methods

### 3.1 Functional — install + playback setting

1. Soft-exit Host on Guest-A/B; expand Host patch; stamp must contain `PLAYBACK-DEVICE=1 EN-UI=1`.
2. Write `SoundSynchro.json` with `LocalPlaybackDeviceId="*"` and role TX/RX as above; open SWB via pulse.
3. Confirm JSON round-trip retains `LocalPlaybackDeviceId` and matrix comes up (`Audio matrix up` + `MESH_OK peers=1`).
4. UI check (Host-PC / code review): tier dropdown items are `N — {EnglishName}` only; playback label `Local playback (single-PC output):`; first combo item `All devices`.

### 3.2 Latency — software softSigma (guest stages)

1. Guest-A/B already MESH’d at tier 6.
2. Clear Guest-B `swb-latency-stages.log`; Guest-A plays a fixed WAV (~12 s) via PlayProbe (play-only).
3. Read Guest-B stage marks: `L6_rx_push` (energetic RX) and `L9_first_audible` → `softSigma` (= L9−L6 when L6 precedes L9).
4. Design gate (handbook 05b): **t6 software Σ &lt; 40 ms** (`softSigma`); dual-VM E2E wall may add +30–80 ms (VMware audio path).

### 3.3 Host-side dual process INCLUDE (exploratory)

Host-PC INCLUDE of each `vmware-vmx` PID while Guest-A plays — intended for E2E similarity. Blocked when guest PCM does not reach Host-PC WASAPI (documented separately); not used as pass/fail for this feature.
