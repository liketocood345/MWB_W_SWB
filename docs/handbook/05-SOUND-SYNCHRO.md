# 05 · Sound Synchro

1. 读取本地 Garage / MWB SecurityKey（及可选机器表提示）。
2. SWB 握手仅面向同密钥对端；失败 **静默纯 MWB**，不阻断键鼠。
3. 成功对端进入发声矩阵（可勾选包含/排除）。
4. 可选：本机 WASAPI loopback → 对端；对端流 → 本机立体声混合。

传输：UDP **15201**（控制 TCP **15200**），与 MWB **15100/15101** 分离。

## 布局模式（三选一）

设置中切换（同一矩阵，仅空间/混音模型不同）：

| 模式 | UI | 行为 |
|------|-----|------|
| **Sync only（单纯同步声音）** | 无环绕舞台（提示文案） | 各路立体声 **等增益中置**，只做同步/混音，不做方位 pan |
| **2D ring** | 环 + 环上设备点 | **拖动点**改变方位角 |
| **3D sphere** | 球面点 | **拖空白**改观察视角；**选中点再拖**改设备方位/仰角 |

布局写入 `%LOCALAPPDATA%\Microsoft\MWB-SWB\SoundSynchro.json`（`AzimuthDeg` / `ElevationDeg` / `Radius` / `SpatialMode`）。

### 初始位置：从各机自报，不在连接后重排

- 每台电脑在本地 JSON 里保存 **本机** 发声点位（本机 `HostName` 对应的 pose）。
- 握手 / name-probe 时把自己的 `azimuth` / `elevation` / `radius` 带给对端。
- 对端收到后 **Upsert** 进矩阵布局；**禁止**按「连接顺序 × 60°」给新对端重新分配初始角。
- 本地尚无保存点时，本机默认正前方（`AzimuthDeg=0`）；对端在尚未报到前可暂用中置，报到后立刻覆盖。

MVP：方位 pan + 可选距离衰减（完整 HRTF 不进本阶段）。Sync only 忽略衰减与方位。

## Force sound sync（强制声音同步）

- **关**：低延迟优先，允许微不同步。
- **开**：局域网 RTT 校准；以最慢路径为基准，先就绪端 **播放侧等待**；目标对齐精度约 **±30 ms**（受校准误差与时钟漂移限制）。
- 校准失败：矩阵仍可用，日志提示降级，**不拖垮 MWB**。
