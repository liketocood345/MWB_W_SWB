# 05b · 发声→播放全链路耗时预算

> **维护规则**：改帧长 / WASAPI / 水位 / 协议头 / 回声路径 / **档位语义** 时，必须同步更新本表与实现（`AudioTier` / `AudioMatrixService`）。验收以本表对照日志。

**t0**：Δ 来自 ForceSync 水位（非 Task.Delay）；sticky+能量门阻断。双 VM softSigma≈142ms（有能量RX→first audible）。
